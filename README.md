## 🏢 Business Concept Overview

**Aura Studio & Journal** is an editorial platform and digital agency portfolio focused on high-performance web engineering, modern layout aesthetics, and scalable design tokens. The multi-page platform is engineered for visual elegance, intuitive navigation across interconnected views, and lightweight responsiveness for tech leads, designers, and web developers.

---

## ✨ Features & Multi-Page Sections

* **Unified Single Stylesheet Architecture:** Built strictly under a centralized `css/style.css` file utilizing CSS custom properties (`:root`) for 100% style consistency across all pages.
* **Sticky Glassmorphic Navigation:** Fixed blurred header with an active page indicator (`.active`) dynamically showcasing the current route.
* **Two-Sided Interactive Split Hero:** Left-aligned bold typography with dual action triggers paired with a right-sided floating glowing code showcase frame.
* **Live Metrics & Values Grid:** Fast-loading metrics banner highlighting key engineering standards, paired with a 3-pillar architectural capabilities grid.
* **Interactive Multi-Filter Blog Engine:** Sticky sidebar featuring real-time tag-based category and hashtag filtering (Web Development, UI/UX, Performance, Stylesheets, Flexbox, Animation).
* **Dynamic 6-Post Pagination:** Automated pagination engine displaying 6 cards per page with smooth scrolling, number buttons, and previous/next states.
* **Pure CSS Quick-Reader Modals:** Accessible preview dialogs triggered via CSS pseudo-selectors for instant article skimming without extra scripts.
* **Dedicated Long-Form Article Page (`post-single.html`):** Complete editorial article view featuring syntax-highlighted code blocks, blockquotes, breadcrumbs, and an author card.
* **Engineering Milestones & Bio (`about.html`):** Developer portrait showcase, skill pill badges, and a progressive timeline of shipped products.
* **Multi-Channel Contact Suite (`contact.html`):** Styled contact form with validation alongside physical office details and direct developer links.
* **Zero Horizontal Scroll Responsiveness:** Fully tested mobile-first flexbox and grid layouts rendering across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack & Technologies

* **HTML5:** Semantic document outline (`<main>`, `<article>`, `<aside>`, `<nav>`), accessible labels, and SEO meta tags.
* **CSS3:** Custom Cyber-Emerald & Gold theme tokens, Flexbox, CSS Grid, keyframe animations, glassmorphism (`backdrop-filter`), and fluid typography.
* **Vanilla JavaScript (ES6+):** Real-time category/tag filtering logic, card visibility manager, and dynamic pagination math.
* **Icons & Typography:** Google Fonts (Playfair Display & Plus Jakarta Sans), Font Awesome 6.5 (Vector Icons).
* **Hosting & Deployment:** Git, GitHub, Vercel.
